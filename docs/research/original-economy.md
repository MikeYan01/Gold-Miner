# 原版经济基线与创新覆盖

核查及实施日期：2026-09-21。

## 结论与本次范围

**本项目保留原版前10关累计目标、十类资源供给、随机商店、生成时定价及钱袋开奖，再单独叠加已确认的创新。** 第11关以后的目标已改为下文的线性增量封顶方案；原版目标公式与表格保留作历史基线，不再代表现行后期目标。

研究在内存中解析并最小重放原始经济动作，包括目标递推至1000关、五类商品的完整整数报价范围、价值加成与库存快照；逐个重建30个目标帧的存活资源实例，并对照两份文件。**没有运行完整原版播放器，也没有测量原坐标下60秒实际可得收入。** 未保存或移植原作图像、源码列表、二进制、音频及关卡坐标。

## 1. 钱包、目标和内部关卡类别

原作新游戏为钱包0、炸药0、时间基值60、内部类别数10。中间目标基数375在启动时加275，**实际第一关目标是650**。

显示关数为`n`，内部资源类别为`k`。目标公式：

```text
n <= 10: G(n) = 375 + 275n + 135n(n − 1)
n > 10:  G(n) = 15275 + 2705(n − 10)

n <= 10: k(n) = n
n >= 11: k(n) = 4 + ((n − 11) mod 7)
```

因此没有第十关终局；之后资源类别4～10反复循环，累计目标继续增加。

成功条件是**当前累计钱包≥目标**。购物直接扣同一钱包，不补偿目标，不按本关新增收益重算，不按剩余时间追加现金。

例如过关后有1000元，花100元购买饮料后剩900，第二关目标仍1195，需要再赚295。后期富矿关的盈余要留给贫矿关，不能把全部关卡改成每关独立赚够2705。

### 本项目现行后期目标（2026-09-25）

前10关不变，第11～20关用10次递增将新增目标从2,705抬到8,000，每次先四舍五入再累加；第21关起固定增加8,000：

```text
G(10) = 15,275
11 <= n <= 20:
  delta(n) = round(2705 + (8000 - 2705) * (n - 10) / 10)
  G(n) = G(n - 1) + delta(n)
n > 20:
  G(n) = 71,450 + 8,000 * (n - 20)
```

因此第11／15／20／21关目标分别为18,510／36,744／71,450／79,450。单人、双人相同，仍比较购物扣款后的累计钱包；资源类别与生成量不随目标补足。实现为 [`runLevelTarget`](../../src/game/economy.ts)，原版参考函数 `originalLevelTarget` 保留不变。这次将先前10,000封顶下调为8,000；[多配装收入实测](post-ten-income-samples.md)保留此前曲线下的实验记录，并非本次调整后的重新采样。

## 2. 商店不是固定五件商品

`U(a,b)`为两端都包含的均匀整数。**k使用刚完成关卡的内部类别**，既不是下一关，也不是无限增长的显示关数。

| 商品 | 上架条件／概率 | 原始报价 | 原始库存和效果 |
| --- | --- | --- | --- |
| 炸药 | 当前炸药<5时必上架，否则缺货 | `U(1,300)+2k` | 一件，炸药+1 |
| 生力水 | 40% | `U(100,399)` | 一件，下关力量+2 |
| 四叶草 | 40% | `U(1,50k)+2k` | 一件，下关使用幸运钱袋奖池 |
| 石头书 | 60% | `U(1,150)` | 一件，下关两种石头价值×3 |
| 钻石抛光剂 | 50% | `U(1,100k)+200` | 一件，下关钻石部分+300元 |

| 商品 | k=1报价范围 | k=4 | k=10 |
| --- | --- | --- | --- |
| 炸药 | 3～302 | 9～308 | 21～320 |
| 生力水 | 100～399 | 100～399 | 100～399 |
| 四叶草 | 3～52 | 9～208 | 21～520 |
| 石头书 | 1～150 | 1～150 | 1～150 |
| 抛光剂 | 201～300 | 201～600 | 201～1200 |

每个商品只售一次，购买后进入`off`帧移除按钮；炸药也不是可连买三件的库存。下家店重新抽供货和报价。不存在根据钱包自动送便宜商品或保证五件全齐的规则。

炸药库存≥5时，其余四件全缺货概率为`0.6×0.6×0.4×0.5=7.2%`，可出现空店；库存<5时至少有炸药。5是商店供货门槛，不是钱袋奖励或库存计数器的硬上限。

店主的满意／不满只由是否买过商品选择动画，未查到额外罚款、现金奖励或修改下一关目标的动作。

### 当前价格：移除额外通胀

本项目按后续调整取消了额外的3%逐关复利，直接使用原版随机报价：

```text
本次售价 = 本次原版随机基价
```

随机基价和资源类别仍会变化，因此报价不是固定价格；但显示关数本身不再增加倍率。相同类别与相同随机抽样在早期、循环关和极晚期给出相同报价。

窃贼仍有每店共享2次，但只能从实际上架、仍有库存的商品中选择。没有商品就不能偷；同店一捆炸药不能偷两次；重开界面不补货或重置次数。未使用的次数不跨店保留。

### 透支的证据边界

原购买处理器没有余额检查，独立动作重放中0元买100元饮料会变成−100。相关动作中未发现按余额禁用按钮的逻辑，**但未做完整播放器鼠标交互验证**。

本项目有意保留此前的**不允许透支**约束：余额不足禁用购买并明确提示；偷取仍可在0余额时进行。不能把这个产品约束说成原作已证实的规则。

移除复利后，正常生成的报价始终受上表的原版范围约束，不再因显示关数增大而指数膨胀。偷取仍不要求钱包能够支付商品价格。

## 3. 增值道具和钱袋都在生成时定案

石头书将小石头11→33、大石头20→60，**不是五倍**；骨头和骷髅不增值。抛光剂将钻石600→900、携钻鼹鼠602→902，普通鼹鼠仍2元。

原作流程：商店重置上关标志→购买设置下关标志→物件Load读取并保存价格→捕获复制价格→收回发放已保存金额。

本项目对应做法：

- `baseValue`保留基础面值；
- `applyRoundValue`在新关初始化时根据购买的物品写入`value`；
- 收回时不再重复应用商店乘数；
- 两种收藏家均增加15%，“富贵险中求”再乘1.5；在这个原版金额之上计算，携钻鼹鼠的2元身体价值仍不吃钻石乘数；全部售价加成后逐件四舍五入，再应用克隆；
- 点石成金得到新黄金，不延续石头书的旧加成。

### 六面钱袋奖池

| 四叶草 | 骰面 | 初始化时奖品 |
| --- | --- | --- |
| 无 | 1～3 | 均匀整数1～600元 |
| 无 | 4 | 本关strength |
| 无 | 5 | 一捆炸药；若初始化时库存>3则为100～199元 |
| 无 | 6 | 800元 |
| 有 | 1～2 | 本关strength |
| 有 | 3～4 | 一捆炸药；若初始化时库存>3则为300～599元 |
| 有 | 5～6 | 700元 |

奖励在Load时固定，收取前库存变化不会使它临时改奖。库存3时生成的炸药袋，即使收取前已有5捆，仍增加到6，不触发兑换或上限。

仅算现金、不折现力量和炸药的价值，每袋期望：

| 生成时状态 | 直接现金期望 |
| --- | ---: |
| 无四叶草，库存≤3 | 3403/12≈283.5833 |
| 无四叶草，库存>3 | 308.5 |
| 有四叶草，库存≤3 | 700/3≈233.3333 |
| 有四叶草，库存>3 | 2299/6≈383.1667 |

因此四叶草提高强力／炸药机会，不保证提高直接现金期望。

本项目现行钱袋规则（2026-09-25）：

- “大力”：不再覆盖奖池，和普通能力一样采用上方六面抽奖，仍可能获得本关strength；四叶草和炸药库存兑换也遵循同一规则。
- “钱袋子”：唯一的奖品覆盖，必为随机现金，继续使用100～450／四叶草400～800区间，重量固定为钻石2；与大力同时拥有时也不变。
- 0～4袋总数量概率保持此前约定，不采用原版模板固定袋数。

所有奖品仍在关卡初始化时决定。

证据：O钱袋215 `[200543,201173)`、A钱袋384 `[178777,179442)`；现金入账O奖励剪辑308第32帧 `[264992,265078)`、A剪辑473第32帧 `[243502,243598)`；炸药奖励O `[266149,266232)`、A `[244674,244767)`。

### 为什么不能自动填满目标差额

类别4的第二／第三模板固定面值1077、两袋；即便袋子都出800，面值也只有2677，低于原版后期单关增加的2705。这不是需要填补的程序漏洞，而是原作累计钱包设计的一部分。现在关卡生成不再为保证每关独立达标而凭空补钻石或金币。

### 本项目的地图覆盖

`resource-profiles.ts`保存上述数值；`levels.ts`使用自己的错列候选点和独立布局方法，确保材料在钩子范围内、初始不重叠。不会声称位置、障碍路径或实际难度与原版逐点相同。

保留的明确创新：

- 按类型四舍五入保留原数量的80%大中黄金／钻石／携钻鼹鼠，以及65%其他材料；再将直接生成的钻石（含双人增量）减半，奇数部分以50%概率保留，能力转换不重复减半；原始数量表仍保留作基线，不改目标或基础物重；
- 大中黄金整体避开矿场上部40%，钻石优先落在下三分之一；普通鼹鼠多数位于中上层，携钻鼹鼠默认仅在中下层，“透气的鼹鼠”使携钻鼹鼠更偏向中上层，不再改变速度或重量；
- 双人保留独立宝藏增量，其中钻石同样减半；基础时限40秒；
- 所有阶段的自定义0～4袋分布；
- TNT保底提高为第1～3关3个、第4～24关4个、第25关起5个；原模板更多时不削减，保留拆弹专家和富贵险中求的作用；
- TNT基础半径回调至250，即最初125半径的2倍、面积4倍，判定与爆炸圈同步取消额外的视口长边放大；85%的布局优先安排一对近邻TNT，其余优先分离，空间受限时选择关联最少的位置，不再主动把全图连成一条炸药链；
- “富贵险中求”（原名“险中求财”）仅用爆炸半径的75%，即187.5基础半径判定附近宝藏，仍计入物品半径；高亮与抓取判定一致，不改变TNT实际爆炸范围；
- 直接触碰普通TNT爆炸后，钩上保留1元、重量2的碎片；慢燃引信仅点燃并穿过TNT，不凭空挂上碎片；
- 黄金以10%概率转钻石、额外1只携钻鼹鼠、安全TNT及其他能力加成；老主顾保证上架大力水、四叶草、抛光剂，仍正常定价和限购；
- 时间银行在达标提前收工或提前清空矿场时，按界面剩余整秒×20追加金币；这是自定义能力，不是原版通关奖励，也不再增加下一关时间；
- 先前已确认的后段鼹鼠速度上调；
- 第1/4/7/10关前最多四次共享三选一，未选的两张本局不再出现，四轮共展示12种不同能力，重开清空展示记录；
- 全屏适配、等比例物件和原创素材。

原作名义总面值不是60秒内实际可赚数，也不能忽略TNT损失、移动物件、重物回收时间和误抓。基础规则与原始数量表有来源证据；实际出矿数量经过上述自定义调整，不把独立布局的真人体验包装成已完成实机对照。
