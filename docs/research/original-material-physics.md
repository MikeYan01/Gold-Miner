# 原版物件重量、生力效果与回拉时间轴

核查与实现日期：2026-09-21。

本文保存原版物理证据与适配方法，第6节维护当前抓钩和爆炸规则。现行能力数值见[经济文档的能力表](original-economy.md#能力概览)；钱袋奖池、商店及经济适配证据也由该文档统一维护，原版规则与自定义覆盖分别标明。

## 来源、方法与边界

本次逐项比对了两份有明确来源的游戏：

| 样本 | 来源 | 文件指纹 |
| --- | --- | --- |
| O | [历史 GameRival 官网文件快照][O]，由[官方游戏容器][OP]引用 | 298,961字节，SHA-1 `c80f32d6d2c91c2d7d629285e87af15476fe9822` |
| A | [CartoonDan 作者网站文件][A]，由[作者游戏页][AP]引用 | 172,856字节，SHA-1 `fd34a864681315b430e138c6107f76946f417e38` |

两份文件均为550×400、18 fps，SWF格式版本分别为5和17。本报告涉及的物件参数、状态变化和回拉位置序列一致，不代表全部游戏内容一致。

研究在内存中解析原文件的物件初始化、AVM1动作、事件与时间轴；每版用最小解释器重放768组钱袋分支及随机端点，并对回拉动作进行状态重放。事件队列与播放语义对照了Ruffle实现。**没有运行完整Flash播放器，也没有进行真实播放器墙钟计时。** 未保存或移植原作图像、声音、游戏源码、二进制文件。

本项目保留自己的全屏坐标、碰撞、摆动与伸钩机制。回拉采用原始18 Hz状态规则与精确轴向位移数据，按画布高度和当前绳子投影换算；它不是把旧版整套画面或结算动画照搬进来。

## 2. 钱袋重量不是均匀正数

原作在钱袋内部实例Load时先四选一：

| 分支 | 概率 | 重量 |
| --- | ---: | --- |
| 正数随机 | 25% | 均匀整数1～9 |
| 负数随机 | 25% | 均匀整数−1～−5 |
| 固定重袋 | 25% | 9 |
| 固定快袋 | 25% | −1 |

合并后：−5／−4／−3／−2各5%，−1为30%，1～8各1/36，9为5/18。没有0，也没有连续小数。

重量在初始化时确定，捕获后不重抽；其抽取不读取钱袋奖励、金额或四叶草状态。来源：O `[200978,201173)`、A `[179247,179442)`。

**负数是有效参数，不应改为正数或做最小重量截断：**

- 重量−1启用本次抓钩的快收模式，不会丢失袋内奖励。
- −2～−5继续参与普通“力量减重量”；例如饮料后力量12、重量−5，普通步长为17。
- 原版强力是固定模式替换，不是取普通与快收两者的最大值，所以这个17步长的特殊袋子可以略快于稳态16步长的强力回收。

本项目普通钱袋已经采用此重量分布。“钱袋子”能力仍是自定义覆盖，固定为钻石重量2，因此文案改为“按钻石重量”，不再声称它比所有原版随机袋子都轻。

## 3. 两种生力机制

### 商店大力水：下一关力量10→12

开始游戏及商店重置普通力量为10；购买饮料增加2。购买后商品切到`off`帧并移除按钮，正常商店不能重复购买同一瓶。下一家店又重置为10，不跨关累积。

原作普通回收使用：

```text
目标时间轴帧 = 当前帧 + 力量 − 重量
```

因此饮料对50／100／250／500元金块的主体提速分别为9/7、5/3、2、3倍，**不是统一+65%**。

定位：O力量初始化55505、商店重置104391、购买赋值113764及按钮移除114006；A对应51273、115356、125014、125274。

### 袋中strength：本关余下时间的快收状态

对两版`strength`全局状态的全部读写进行了追踪：

| 操作 | O | A |
| --- | ---: | ---: |
| 关卡启动清零 | 89358 | 100329 |
| 商店阶段清零 | 104365 | 115332 |
| 袋中power奖励设为1 | 265148 | 243702 |
| 回收处理器读取 | 248980 | 226522 |

其他同名引用属于动画帧标签。没有找到按秒递减、按回收次数消耗或收回一次后清除该全局状态的逻辑。

因此已改为：**钱袋收回并结算出生力奖励后，后续回收一直使用快收模式，直到进入商店／新关卡。** 重复获得只保持状态为真，不叠加，不刷新计时；四叶草不延长时效。快收分支不读取普通力量，故商店饮料的+2不再叠到它上面。

本项目“大力”能力在原版模式决定后额外加速载物回拉时钟，也适用于生力快收模式；它不改变原版力量、重量或空钩速度。具体加成见[能力表](original-economy.md#能力概览)，它也不覆盖[普通钱袋奖池](original-economy.md#本项目的钱袋数量与能力覆盖)。

## 4. 18 Hz回收状态机与精确位置

原回收剪辑为O的299、A的464。控制器入口与处理器分别位于O `[248687,249080)`、A `[226174,226628)`。

- 回收入口：重量大于1时停止自然播放；−1或空钩设置本次局部快收。
- 普通事件：跳前`力量−重量`帧并停止。
- 本次局部快收或本关strength有效：跳前15帧并继续播放。
- 事件先入队，播放中的剪辑自然前进一帧，随后执行事件，所以快收稳态一般为16；重物进入全局强力时首周期可只有15。

原始轴向位置从F44的8137 twips（406.85）到F293的249 twips（12.45），共有250点。相邻位置减少31或32 twips，共80个31、169个32。以整数位置十进制、逗号连接后的SHA-256为：

```text
87b913f6e51337d128621258ac24f65d3a7c0db04ba33955637a8e65ae59d1ff
```

这些纯数值运动数据已记录在 `src/game/hauling.ts`，并通过完整校验值核对。实现不再用平均1.583935743像素/帧冒充逐点相同。

### 末段不是简单夹到293帧

- 286～292各帧恢复播放。
- 293移除回收控制器。
- 293～316各帧都有相同的结算动作。
- 回收事件没有`当前帧<285/286`之类保护条件。

从普通、停止状态的F285开始，轨迹为286→288→290→292→293。快收处于播放状态时，从F280可直接跳到296结算，从F285可跳到301；跳过293也会应用显示列表移除，并在实际目标帧执行结算。若从正在播放的292开始，自然推进先到293，控制器已被移除，其排队事件不会再跳跃。

实现保留游标、播放状态、控制器存活状态与本次快收标志。**不会把所有跳转伪装成`min(target,293)`**，也不会将负重量普通步长17强制降成16。

原文件整个剪辑长327帧，但本次合法回收模式落点均在重复结算范围内。端点定位：O 255465～255794、控制器移除255690；A 233290～233619、移除233515。

## 5. 适配到当前游戏

- 按18 Hz推进原版回收状态；显示层在当前状态和确定的下一步之间插值，使钩子、绳索和货物按设备刷新率连续移动，不把原版18帧的停格感带到现代显示。插值不改变实际状态、碰撞、结算或回拉耗时。
- 原始轴向距离按当前Canvas高度映射，斜绳再按视口投影校正，避免宽屏横向拉伸偷偷加速。
- 折线绳路同样换算到原版时间轴，具体约束见[直角转弯与射线](#直角转弯与射线)。
- 捕获点对齐最近的原版时间轴样本，并保留亚采样偏移，避免命中瞬间跳位置。
- 超宽屏可能产生长于原作舞台的绳路；超出原始样本范围的部分按原主体位移密度延续，进入已测范围后使用精确位置表。
- 空钩、炸药销毁货物后的本次快收，与本关袋中strength分开保存。
- 常驻能力只额外修饰载物回拉时钟；普通、商店饮料和袋中快收的源规则不因它被改写。
- 暂停不消耗回拉时钟；生力标记跨多次回收保留，进入商店和下一关时清除。

这复刻的是相关物重、力度和回收状态规则，不是原版完整输入处理、图形或开奖动画。原版外层摆角矩阵本身有约0.99656～1的微小轴尺度差异；本项目使用统一投影，不能把整幅屏幕称为逐像素还原。

### 更新后的引擎测量

在原始1200×720比例下，设置纯回拉距离为360逻辑单位（画布高度的一半），使用真实引擎以1毫秒步长运行至收回。以下只比较原版物理与补给，不包含会随玩法调参的常驻能力，也不包含出钩和瞄准等待：

| 对象／效果 | 模拟耗时 |
| --- | ---: |
| 50元金块，无加成 | 1.000秒 |
| 100元金块，无加成 | 2.334秒 |
| 250元金块，无加成 | 3.445秒 |
| 500元金块，无加成 | 6.834秒 |
| 500元金块，仅商店饮料 | 2.334秒 |
| 500元金块，袋中strength | 0.445秒 |
| 500元金块，饮料＋袋中strength | 0.445秒 |

此前报告的7.01秒只按主体平均速度推导；这里的6.834秒还包含286～292帧恢复播放的末段行为和离散采样对齐，因此两者不应直接当作矛盾。

## 6. 当前抓钩与爆炸规则

以下是当前项目的自定义玩法，不是对原版全部输入和碰撞行为的复刻。操作键位见[使用说明](original-assets.md#键位与触屏操作)；能力获得方式及收益见[经济文档](original-economy.md#5-本项目当前玩法与能力)。

### 直角转弯与射线

直角转弯允许出钩后再次按下钩键，在原位置只改变朝向、不移动拐点，每钩一次；抓到物品或开始回收后不能再转，下一次出钩重置。偏左的出钩向右转，偏右向左转，完全竖直时在发射时随机确定一侧，预览、暂停或缩放不重抽。两名玩家独立使用；宽屏或竖屏上的可见夹角都保持90°。

转弯后仍在首个阻挡物或地图边缘停下。空钩、绳索和载物都沿原折线返回，将两段投影长度相加后套用原版回拉时间轴，不以起终点直线抄近路。触屏仍使用同一发射按钮，转弯可用时变为转弯按钮。

射线每名玩家在出钩前只显示一条直虚线，终点为首个阻挡物，不预测移动目标。没有直角转弯时，射线只在出钩前显示；有该能力时，未转弯的伸钩从当前钩尖实时预览“现在转弯”的路线，转弯后显示剩余前进方向，回收时隐藏。碎石机可让预览透过石头，但预览本身不销毁物件。

### 深渊巨口与碎石机

深渊巨口同时扩大钩子宽度和命中半径，仍只捕获第一个正常目标；增大的命中范围也适用于碎石。

碎石机对两名玩家都生效，只粉碎钩子实际触碰的、尚未被认领的大小石头，伸出和回收途中都有效，绳子本身不碎石。石头立即消失，不产生可收集碎片，不计作采集、不付钱，也不消耗克隆，即使有石头书也一样。

伸钩仍被第一个非石头物件正常阻挡，其后尚未碰到的石头保留。黄金、钻石、鼹鼠、骨头、头骨、钱袋、TNT和TNT碎片均不被粉碎，真实爆炸行为不变。[碎石视觉与音效](original-assets.md#碎石反馈)只作反馈，不参与伤害、碰撞或回拉速度。

### TNT与主动炸药

TNT基础爆炸半径为250，是最初125半径的两倍、面积四倍；伤害判定和爆炸圈使用同一基础半径，判定还计入目标物件半径。除了正常精灵比例外，不再额外按视口长边放大。附近资格的能力加成采用独立的[富贵险中求判定](original-economy.md#抓取转换与收益)，不能把它的较小范围当成爆炸范围。

普通及连锁TNT爆炸只销毁地下未认领的物件，任意一名玩家已挂钩的货物都受保护；主动使用炸药仍会销毁自己的货物。直接碰到普通TNT后，钩上保留不再爆炸的碎片，价值1元、重量2。拆弹专家会让完整TNT安全可回收，但不禁用主动炸药。

## 7. 为什么替换旧的连续速度公式

2026-09-21 的初步调查发现：按各自画布高度的一半比较，旧实现的500元黄金约需3.09秒，原作主体段推导约7.01秒，归一化速度相差约2.27倍。旧实现用重量作连续速度公式的分母；直接把重量5改成原作的9仍不能还原“力量减重量”的时间轴规则。

这推动了本文的完整物件调查和18 Hz模型替换。3.09秒是旧实现基线，7.01秒是忽略末段差异的静态推导，均不是现行完整回拉的墙钟实测。保留这一区别，比继续维护两份“当前速度”表更重要。

完整旧公式、比较表和当时的修改边界见固定版本的[初步回拉调查](https://github.com/MikeYan01/Gold-Miner/blob/90cd3ed32964e3706a08060a72401bf8df5c3343/docs/research/original-gold-hauling.md)。原版经济后来也已接入；奖池和报价证据由 [original-economy.md](original-economy.md) 统一保存，不再在物理文档中重复维护旧经济规则。
